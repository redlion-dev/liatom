# Security

liATOM is open for review by anyone, with any tools or models. See [docs/ai-audit.md](docs/ai-audit.md).

- **Before mainnet launch:** report findings as public issues using the template in `docs/ai-audit.md`.
- **After launch:** do not disclose exploitable issues in public. Use the private contact published with the
  contract address (to be set by the maintainers before launch).

The first mainnet launch is capped at 100 ATOM total value (`max_tvl`). The cap is raised only after review passes
and time without incidents. No third-party paid audit has been done; do not treat the absence of findings as proof of safety.
